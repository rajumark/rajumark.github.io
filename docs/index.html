Open source · Kotlin compiler plugin

Kernelin

Write GPU code in plain Kotlin. Add @Kernel to a function and the compiler turns it into a GPU shader that runs through WebGPU on desktop, browser or Android — and the same function still runs on the CPU for unit tests.
